Hapag-Aklanon Recipe API Documentation

REST API for managing recipe data stored in Firebase Realtime Database. Supports Cloudinary for image uploads.

https://hapag-aklanon.onrender.com

GET /api/recipes

Retrieve all recipes with pagination support.

Query Parameters

Parameter Type Default Description
page integer 1 Page number for pagination
limit integer 10 Items per page (max: 100)
Example Request
curl "https://hapag-aklanon.onrender.com/api/recipes?page=1&limit=5"
Example Response
{
  "success": true,
  "data": [
    {
      "id": "-Nk123...",
      "location": "MAKATO",
      "dish_name": "Iniraran",
      "description": "Grilled pork or chicken...",
      "ingredients": ["1 kg pork...", "1/2 cup vinegar..."],
      "procedure": ["In a large bowl...", "Cover and marinate..."]
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 5,
    "total_items": 6,
    "total_pages": 2,
    "has_next": true,
    "has_prev": false
  }
}

}
POST /api/recipes

Create a new recipe. Requires image upload or valid image URL.

Request Body (JSON)

{
  "location": "NEW_LOCATION",
  "dish_name": "New Dish Name",
  "description": "Description of the dish",
  "ingredients": ["ingredient 1", "ingredient 2", "ingredient 3"],
  "procedure": ["Step 1", "Step 2", "Step 3"],
  "image_url": "https://example.com/image.jpg",
  "cooking_time": 60,
  "servings": 4,
  "category": "Main Course"
}
Example Request
curl -X POST "https://hapag-aklanon.onrender.com/api/recipes" \
  -H "Content-Type: application/json" \
  -d '{
    "location": "KALIBO",
    "dish_name": "Kinilaw",
    "description": "Fresh fish ceviche",
    "ingredients": ["1 kg fresh tuna", "1 cup vinegar", "Ginger", "Onion"],
    "procedure": ["Clean the fish", "Slice into cubes", "Mix with vinegar"]
  }'
Example Response
{
  "success": true,
  "message": "Recipe created successfully",
  "data": {
    "id": "-Nk456def...",
    "location": "KALIBO",
    "dish_name": "Kinilaw",
    "description": "Fresh fish ceviche",
    "ingredients": ["1 kg fresh tuna", "1 cup vinegar", "Ginger", "Onion"],
    "procedure": ["Clean the fish", "Slice into cubes", "Mix with vinegar"]
  }
}

GET /api/recipes/search

Search recipes by location or dish name.

Query Parameters

Parameter Type Required Description
q string Yes Search query string
field string No Search field: location, dish_name, or both (default)
page integer No Page number (default: 1)
limit integer No Items per page (default: 10)
Example Requests
# Search by location
curl "https://hapag-aklanon.onrender.com/api/recipes/search?q=MAKATO&field=location"

# Search by dish name
curl "https://hapag-aklanon.onrender.com/api/recipes/search?q=Iniraran&field=dish_name"

# Search both fields
curl "https://hapag-aklanon.onrender.com/api/recipes/search?q=chicken"
PUT /api/recipes/

Update an existing recipe. Supports partial updates.

URL Parameters

Parameter Type Description
recipe_id string The unique identifier of the recipe *required

Request Body (JSON) - Partial updates allowed

{
  "dish_name": "Updated Dish Name",
  "description": "Updated description"
}
Example Request
curl -X PUT "https://hapag-aklanon.onrender.com/api/recipes/-Nk123abc..." \
  -H "Content-Type: application/json" \
  -d '{"dish_name": "Updated Iniraran"}'
POST /api/recipes/bulk

Insert multiple recipes at once in a single request.

Request Body (JSON)

{
  "recipes": [
    {
      "location": "LOCATION_1",
      "dish_name": "Dish 1",
      "description": "Description 1",
      "ingredients": ["ing1", "ing2"],
      "procedure": ["step1", "step2"]
    },
    {
      "location": "LOCATION_2",
      "dish_name": "Dish 2",
      "description": "Description 2",
      "ingredients": ["ing3", "ing4"],
      "procedure": ["step3", "step4"]
    }
  ]
}

Error Responses

400 Bad Request
{
  "success": false,
  "error": "Error message describing the issue"
}
404 Not Found
{
  "success": false,
  "error": "Recipe not found"
}
500 Internal Server Error
{
  "success": false,
  "error": "Internal server error message"
}

Recipe Structure

The complete structure of a recipe object in the database. 

{
  "id": "string (auto-generated)",
  "location": "string (required)",
  "dish_name": "string (required)",
  "description": "string (required)",
  "ingredients": ["string", ...] (required),
  "procedure": ["string", ...] (required),
  "image_url": "string (optional)",
  "cooking_time": integer (optional, in minutes)",
  "servings": integer (optional)",
  "category": "string (optional)"
}
